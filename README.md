# Empires of Yore (帝国往事)

**「帝国往事」(Empires of Yore) — 剑客群组服（Swordsman Group Uniform, SGU）定制 Minecraft 模组**，基于 **NeoForge 21.1.248 / Minecraft 1.21.1**（Java 21）构建。

## 内容

### 玩法与进度
- **宝箱战利品表**：`empire:chests/lv1` ~ `lv9`、`lv6_thunder`（红红火火 Lv.6⚡️）与 `cheating_lv1~3`（诈骗箱），共 13 张；前 10 张必定开出 4~6 个名为「剑客群组服」的烤马铃薯，宝箱物品按等级逐级升级（附魔、装备、稀有材料等）
- **进度**：「剑客荣光」标签页——10 个隐藏宝藏进度（对应开启各级宝箱，奖励 100 XP）、「术友汇玩家不得不品的一环」「新手期已过！」（与清朝僵尸 `iss_magicfromtheeast:jiangshi` 相关，奖励 390 XP），以及「奉献恒心」（**碳钢锄耐久耗尽时**触发，奖励 100 XP）
- **自定义采矿维度 `empire:mining`**：无地表、全地底洞穴世界（0~1024 层，上下基岩封闭，出生点 512 层），256 层以下石头替换为深板岩，矿石更密集，64 层以下极低概率远古残骸，384~800 层石英矿、128~256 层深层石英矿；怪物生成率更高且全部获得加强（生命/攻击/移速/追踪加成）
- **石英矿石**：`empire:overworld_quartz_ore`（主世界 0~63 层）、`empire:deepslate_quartz_ore`（主世界 -64~0 层），均与下界石英矿石行为一致（除贴图）

### 工业体系：能源与矿石
- **能源石体系**：能源石矿石（铁镐可采，掉落能源石，可作熔炉/机器燃料）；高级能源石矿石（**主世界 / 采矿维度 / 下界 / 末地**四处生成，需**硬铝镐**才能开采，掉落高级能源石，燃料 3200 点、橙色稀有）
- **铝土矿**（主世界，铁镐）：掉落铝土粉 2~4 个（受时运加成，如青金石）；含深层变种
- **冰晶石**（下界，荧石状发光方块）：方块 ⬌ 冰晶石粉 1:4 互转（附魔精准采集挖取方块，普通挖掘得到 4 粉）
- **镁矿**（沙漠 / 恶地，-64~64 层，钻石镐）：掉落粗镁
- **铬矿**（-64~64 层，**需下界合金镐**）：掉落粗铬
- **钛矿**（主世界 / 下界 / 末地，钻石镐）：掉落粗钛

### 冶炼机器（能源石/燃料驱动，进度 = 机器工作秒数，完成后在方块上方获得经验）
- **电解炉**：只烧能源石/高级能源石；带**冰晶石粉试剂槽**。
  - 铝土粉 ×3 + 冰晶石粉 ×1 → **铝锭**（1800t）；无冰晶石粉时仍可炼铝，但**能源消耗 ×4**
  - 粗镁 → **镁锭**（2400t），**能源消耗 ×2**
- **工业熔炉**：槽位 2 个，支持原版熔炉燃料与熔炼配方；另含：粗铬 → 铬锭（360t）、龙骸 → 末影合金碎片（6000t）、煤 → **焦炭**（200t）
- **高级工业熔炉**：槽位 4 个，批量配方（各槽按数量消耗）：
  - 镁锭 ×2 + 铝锭 ×3 + 铬锭 ×1 + 焦炭 ×1 → **硬铝锭**（12000t）
  - 钛锭 ×2 + 硬铝锭 ×3 + 焦炭 ×4 → **钛合金锭**（12000t）
  - 铁锭 ×1 + 焦炭 ×1 → **碳钢锭**（4800t）
  - 粗钛 → 钛锭（7200t）
  - 兼容原版熔炉 / 高炉的所有配方（单槽熔炼）

### 材料与锻造体系
- **焦炭**：煤在工业熔炉中炼制
- **碳钢**：铁锭 + 焦炭 → 碳钢锭（附碳钢块）；铁工具 + 初级升级工具 + 碳钢锭 → **碳钢工具五件套**（耐久 4200 / 速度 6.5 / 等级同铁镐）；碳钢锄损坏触发「奉献恒心」进度
- **硬铝 / 末影合金 / 钛合金**：下界合金 → 硬铝 → 末影合金 → 钛合金 逐级锻造（护甲 + 镐/剑/斧/锹/锄全链）
  - 硬铝镐：3000 耐久 / 10.5 速（等级 5，可采高级能源矿、龙骸）
  - 末影合金镐：3500 耐久 / 17.0 速（等级 6）
  - 钛合金镐：3939 耐久 / 24.0 速（等级 7）
- **升级工具**：初级升级工具（可复制：铜锭环 + 圆石 + 升级工具 → 2 个）；**专业升级工具**（硬铝锭 ×7 + 初阶升级工具 + 冰晶石粉 ×1 → 2 个，用于硬铝→末影→钛合金锻造模板）
- **装备获取途径**：碳钢/硬铝/末影合金/钛合金 四阶装备**均无工作台合成配方**，只能在锻造台逐级升级（铁工具→碳钢；下界合金→硬铝→末影合金→钛合金）；**钛合金装备仅能由末影合金装备升级获得**（模板：专业升级工具）
- **龙骸与末影合金**：击杀末影龙掉落**龙骸**（末地亦有极稀有龙骸矿）；龙骸在工业熔炉熔炼 300 秒 → 末影合金碎片；碎片 ×4 + 硬铝锭 ×5 → **末影合金锭**；末影合金四件套护甲（防火）
- **矿物等级链**：铝土矿=铁镐级 → 铬矿=下界合金镐级 → 高级能源矿/龙骸=硬铝镐级，逐级提升，未达标无法正常采集
- **初音护甲四件套**：初音头盔/胸甲/护腿/靴子（史诗，防火，耐久 1024 系），穿戴时获得**无敌**效果

### ⑪ 青铜体系（比碳钢更早期：高性能、低耐久，比金器更极端）
- **锡矿石 / 深层锡矿石**：主世界与采矿维度生成，常与铜矿伴生（矿脉可替换铜矿石），需**石镐及以上**开采，掉落 **1~3 个粗锡**（受时运影响，附魔精准采集掉落原矿）
- **粗锡** → 任意熔炉/高炉冶炼 → **锡锭**
- **青铜锭**：2 锡锭 + 4 铜锭，按下界合金式摆放（左上、中上锡锭；右上及中部三格铜锭）合成
- **青铜装备**（普通工作台合成，例：3 青铜锭 + 2 木棍 = 青铜镐）
  | 装备 | 关键数值 |
  |---|---|
  | 青铜镐 | 挖掘速度 18（**金镐 1.5 倍**）、等级 2、耐久 79 |
  | 青铜剑 | 伤害 7、攻速与钻石剑相同（-2.4）、耐久 59 |
  | 青铜斧 | 伤害 12、砍伐速度与金斧相同、耐久 59 |
  | 青铜锹 | 速度 18，**无附魔即可瞬间挖掘泥土**、耐久 64 |
  | 青铜锄 | 速度与金锄相同、耐久 159 |

### ⑫ 工业熔炉（及以上）新增配方
- **2 远古残骸 + 3 焦炭** → 3 下界合金碎片（3 分钟，180 EXP）
- **3 龙骸 + 8 焦炭** → 4 末影合金碎片（6 分钟，360 EXP）

### ⑰ 三界钛合金
- **三界钛合金锭**：钛合金锭 / 下界合金锭 / 末影合金锭 / 焦炭 = **4 : 4 : 4 : 9** 放入**高级工业熔炉**四个槽位，**10 分钟**（600 EXP）产出
- **终极升级工具**：钛合金锭 ×7 + 专业升级工具 + 冰晶石粉 ×1 → 2 个
- **三界钛合金装备**：钛合金装备 + 终极升级工具 + 三界钛合金锭 锻造升级（9 件：镐/斧/锹/锄/剑 + 四件套护甲）
- 相比钛合金装备**全属性 +10%**（耐久 4333、挖掘速度 26.4、伤害加成 5.5、护甲防御 9/15/20、韧性 4.4），**挖掘等级 8**

## 构建

```bash
./gradlew build
# 产物：build/libs/empire-<版本>.jar
```

> 版本号规则：`27.<重要更新>.<次要更新>.<Build>`（第一位为年份，首次构建为 27.0.0.1）。

> 国内网络下 Gradle 与依赖下载较慢，`settings.gradle` 与 `build.gradle` 已配置阿里云/腾讯云镜像（官方源兜底）。Android/FCL 用户可用 `./gradlew build copyJarToFcl` 一键部署（仅拷贝当前版本 jar 并清理旧版本 `swordsman-*`/`empire-*`）。
